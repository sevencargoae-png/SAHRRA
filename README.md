# قالب متجر SAHRRA القابل لإعادة الاستخدام

هذه نسخة محلية مستقلة من واجهة المتجر وملفات الصور ونموذج لوحة الإدارة وبرومبت جاهز. انسخ المجلد كاملًا عند بدء مشروع جديد، ثم خصّصه للعميل الجديد قبل النشر.

## قبل تسليم أي نسخة لعميل

1. بدّل اسم SAHRRA/سَهْرة والشعار والنصوص إلى هوية العميل.
2. استبدل رقم واتساب `971504281333` في `dist/index.html` برقم العميل بصيغته الدولية، واختبر رابط الطلب.
3. حدّث أسماء العبايات وأسعارها وأوصافها وصورها داخل `dist/index.html` ومجلد `dist/assets`.
4. أنشئ موقعًا/مشروع استضافة جديدًا للعميل؛ لا تستخدم معرّف مشروع المتجر الأصلي. ملف `.openai/hosting.json.example` نموذج إعداد فقط.
5. اختبر العربية والإنجليزية والثيمات على الهاتف والكمبيوتر قبل النشر.

## ملاحظات مهمة

- أُدرجت ملفات المتجر والصور، ولم تُدرج `.git` أو بيانات ربط الموقع الأصلي.
- `dist/admin-demo.html` نموذج بصري فقط؛ لا يحتوي دخولًا آمنًا أو بيانات حقيقية، فلا تنشره كلوحة إدارة.
- قسم التقييمات موجود كواجهة ونموذج، لكن الإرسال متوقف حتى إعداد خادم وقاعدة بيانات ومراجعة دخول المالكة.
- لا تنشر نسخة لعميل قبل تغيير رقم واتساب والعلامة التجارية والأسعار والصور، وربط أي وظائف خلفية بحساب العميل.
- البرومبت الجاهز: `PROMPT-انسخ-والصق-لبناء-المتجر.md`.

الصفحة الرئيسية: `dist/index.html`.
